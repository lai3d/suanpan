# 自己设计芯片的三个层次

[English](three-stages.md)

"自己设计一颗芯片"可以指三件很不一样的事。它们在成本上相差几个数量级，最后拿到手的东西也完全不同。这个项目按顺序一层一层做，只有前一层拿出了数据，才进入下一层。

| 层次 | 最后得到什么 | 成本 | 本仓库的进度 |
|---|---|---|---|
| 1. RTL + 仿真 | 用 Verilog 写成、能在仿真器里跑推理的设计 | 免费，全部用开源工具 | 已完成 |
| 2. FPGA | 同一个设计在真实硬件上运行 | 一块开发板 | 比特流已能生成，尚未上板运行 |
| 3. 流片（ASIC） | 一颗真正的芯片 | 几千美元起，上不封顶 | 未开始 |

## 层次 1：RTL 与仿真

用硬件描述语言把电路写出来，在仿真器里运行。这时没有任何实物，但设计是真实的：每个寄存器、加法器、存储器都已确定，综合工具可以把它变成门电路。

这一层能证明的事：

- **设计是对的。** 在本项目里指逐位一致：MNIST 的 10,000 张测试图，输出的每个 logit 都和整数参考模型相同。
- **大致有多大、多快。** 把设计综合到开源的标准单元库（SKY130）上，可以得到门数和最长路径的估算。

这一层回答不了的事：真实的连线延迟、时钟分布、存储器的时序、功耗。这些要等物理实现。

用到的工具：仿真用 Icarus Verilog 和 Verilator，综合用 Yosys，全部开源。这一层的具体成果见 [README](../README.zh-CN.md)。

## 层次 2：FPGA

FPGA 是一种内部逻辑可以反复重新配置的芯片。把设计烧进去，它就在真实硬件上、以真实速度、用真实的存储器和时钟运行，而不需要制造任何东西。

这一层新增的东西：

- **仿真之外的证据。** 布局布线工具会针对具体器件检查时序，运行结果可以用逻辑分析仪观察，或者直接看 LED。
- **实测的主频和资源占用**，不再是估算。
- **和外部世界连接的途径**：主机、摄像头、传感器。

成本是一块开发板。对这个设计来说，真正的约束是块 RAM，而不是逻辑。第一个目标板选的是 Sipeed Tang Nano 20K：便宜，块 RAM 够用，板上自带 USB 下载器，并且有能在 macOS 和 Linux 上运行的开源工具链支持。

进度：[`fpga/tangnano20k`](../fpga/tangnano20k) 里的演示工程已经能用开源流程完成综合、布局、布线并打包成比特流，时序余量很大。对布线后的网表做门级仿真，结果与 RTL 一致。它**还没有**在实体开发板上运行过。

FPGA 不是小号的 ASIC。同一个设计做成专用芯片会快得多、省电得多；FPGA 特有的资源（块 RAM、DSP 乘法器）也带不过去。能带过去的是 RTL，以及"它确实能工作"这份把握。

## 层次 3：流片（ASIC）

到这一步，设计才被制造出来。综合之后是物理设计：布图规划、布局、时钟树综合、布线，然后是时序、设计规则、版图与原理图一致性等签核检查。最终产物是交给晶圆厂的版图文件。

这一层有两种差别极大的做法：

- **成熟工艺，拼片流片。** 借助 SkyWater 130 nm 这类开源工艺设计套件，以及 OpenLane 这类开源流程，个人可以把一个小设计放到多项目晶圆上去流片。成本在几千到一两万美元的量级，周期以月计。
- **先进工艺。** 7 nm 及以下，光罩、商用工具和 IP 的授权，加上工程团队，成本在千万美元量级以上。这是公司才做得了的事。

这里的成本只是粗略的数量级，不是报价；真要按它做计划，请先查当前的拼片价格。

层次 3 也是本项目一直往后放的那些东西躲不开的地方：用真正的 SRAM 宏替换行为级存储器、焊盘环、时钟与复位方案、功耗分析，以及芯片回来之后怎么测试。

## 一颗有用的 AI 芯片，除了数据通路还需要什么

乘加核心是其中容易的部分。决定设计有没有用的是另外三件事：

- **存储。** ASIC 的估算和 FPGA 的实现都指向同一个结论：存储器主导面积，也是最紧缺的资源。限制吞吐率的通常是访问权重的带宽，而不是乘法器的数量。
- **编程模型。** 这个设计由主机写入的一张层描述表驱动，换一个网络只需要换存储镜像，不需要改 RTL。这张表就是指令集的雏形。
- **软件栈。** 总得有东西把训练好的模型变成那些存储镜像。在这里它是一个 Python 脚本；对真正的产品来说它是一个编译器，而且往往是工作量更大的那一半。

## 现实的判断

一个小型的自研设计，在通用性上赢不了通用 GPU。但在很窄的场景里可以赢得很明显：只跑一类模型、固定的量化格式、严格的功耗预算。合理的路径就是本项目在走的这条：选定一个负载，先在仿真里证明设计，再在 FPGA 上证明一次，然后才看数据值不值得做成硅片。
